**EN.** Everything in `docs/01`–`docs/07` (the main blueprint) is enough to
start building. This folder goes further: it is an **original, bilingual
synthesis of a much larger body of research** — hundreds of queries across
Thai hydrology, global open-source flood-modeling tools, machine-learning
architectures validated on Thai basins, risk-scoring theory, and
multi-channel alert engineering — condensed into eight dense reference
documents. Every fact, formula, and number here has been cross-checked
against the cited primary sources; where a claim rests on a single study
rather than independent confirmation, it's flagged **(single-source)** so
you know to verify it yourself before relying on it operationally.

**This is a summary and synthesis, not a reproduction of any single
source document.** Treat every citation as a starting point for your own
verification — a challenge like this deserves primary sources, not
secondhand certainty.

**TH.** เอกสาร `docs/01`–`docs/07` (พิมพ์เขียวหลัก) เพียงพอสำหรับเริ่มสร้าง
แล้ว โฟลเดอร์นี้ไปไกลกว่านั้น: เป็น **การสังเคราะห์ต้นฉบับสองภาษาจากงานวิจัย
ชุดใหญ่กว่ามาก** — คำค้นหลายร้อยครั้งครอบคลุมอุทกวิทยาไทย เครื่องมือแบบจำลอง
น้ำท่วมโอเพนซอร์สระดับโลก สถาปัตยกรรมแมชชีนเลิร์นนิงที่ตรวจสอบกับลุ่มน้ำไทย
ทฤษฎีการให้คะแนนความเสี่ยง และวิศวกรรมระบบแจ้งเตือนหลายช่องทาง — สรุปเป็น
เอกสารอ้างอิงเข้มข้นแปดฉบับ ทุกข้อเท็จจริง สูตร และตัวเลขในนี้ตรวจสอบไขว้กับ
แหล่งข้อมูลปฐมภูมิที่อ้างอิงแล้ว หากข้อความใดอิงจากการศึกษาเดียวโดยไม่มีการ
ยืนยันอิสระ จะมีป้ายกำกับ **(แหล่งเดียว)** เพื่อให้รู้ว่าควรตรวจสอบเองก่อนนำ
ไปใช้จริง

**นี่คือการสรุปและสังเคราะห์ ไม่ใช่การทำซ้ำเอกสารต้นฉบับใด ๆ** ถือทุกการ
อ้างอิงเป็นจุดเริ่มต้นสำหรับการตรวจสอบของคุณเอง — ความท้าทายแบบนี้สมควรได้
